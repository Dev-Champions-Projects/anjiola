# Winifred A. Oseni — Data & AI Portfolio

Responsive React + TypeScript + Vite portfolio with no portrait, no graphical logo, and a persistent light/dark theme toggle.

## Setup
```bash
npm install
npm run dev
```
Open the localhost URL printed by Vite. To create a production build: `npm run build` (output: `dist/`). Deploy the repository to Vercel or Netlify with build command `npm run build` and output directory `dist`.

## Customize
- Edit copy, work history, and tool descriptions in `src/App.tsx`.
- Update styling and colors in `src/style.css`.
- Update the contact email constant in `src/App.tsx`.
- This portfolio deliberately does not invent analytics projects, certifications, skill-duration estimates, or links to nonexistent profiles.
- Survey categories: Excel, Power BI, SQL and Python relate to **Office & data analysis**. AI labeling/categorization relates to data annotation and quality review. Do not select specialized CAD, engineering, simulation, GIS, or media-production categories without actual experience.
- Verify every tool's hands-on proficiency and years of use with the portfolio owner before submitting job or survey applications.
